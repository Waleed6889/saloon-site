# Salon Website

A modern, responsive salon website designed with a clean and elegant user interface.

## Features

* Responsive design
* Modern UI
* Services section
* Appointment booking interface
* Contact section
* Mobile-friendly layout

## Tech Stack

* React
* JavaScript
* Tailwind CSS
* Vite

## Run Locally

```bash
npm install
npm run dev
```
